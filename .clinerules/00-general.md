# Общие правила проекта

- Сначала прочитай `AGENTS.md` и `README.md`.
- Поддерживай текущий стек HTML, CSS и JavaScript без сборщика и npm-зависимостей.
- Используй дизайн-токены в `styles/tokens.css`; сохраняй разделение CSS по назначению.
- Соблюдай семантику, клавиатурную доступность, адаптивность и `prefers-reduced-motion`.
- Никогда не добавляй секреты Telegram или Turnstile в клиентский код.
- Не ослабляй серверную проверку Turnstile и обработку ошибок формы.
- Меняй только нужные для задачи файлы и сообщай о необходимых переменных окружения.
- Не запускай тесты, если пользователь не просил их запускать.
