# Правила проекта RIMLAB

- Прочитай `AGENTS.md` и `README.md` до изменений.
- Работай только в этом проекте. Исходный OnixFrame starter не меняй.
- Сохраняй HTML/CSS/JS и структуру CSS по назначению; не добавляй зависимости без необходимости.
- Не минифицируй исходники. Каждый CSS-селектор и каждое CSS-свойство должны быть на отдельных строках.
- Если в корне есть `.prettierrc.json`, используй его настройки при форматировании.
- Header должен оставаться sticky сверху на всём протяжении прокрутки; проверь desktop и mobile, фон, z-index и якорные отступы.
- Сделай адаптивные изображения через оптимизированные форматы и размеры `picture`/`srcset`/`sizes`; не загружай один большой desktop-файл на все экраны.
- Предпочитай фото, предоставленные заказчиком. Не называй стоковые или сгенерированные визуализации реальными работами; пока нет своих фото — оставь отмеченные плейсхолдеры.
- Используй alt, размеры изображения и lazy loading ниже первого экрана; главное hero-изображение загружай приоритетно.
- Подготовь базовое SEO: уникальные title/description, canonical после подтверждения домена, Open Graph, robots.txt, sitemap.xml. Структурированные данные добавляй только после получения проверенных данных бизнеса.
- Не выдумывай цены, адрес, телефон, сроки, гарантии, отзывы и рейтинг.
- Не размещай секреты в браузерном коде. Форма остаётся честно в демо-режиме до настройки Turnstile и Telegram.
- Не запускай тесты, если пользователь не просил их запускать.
