# Правила проекта RIMLAB

- Прочитай `AGENTS.md` и `README.md` до изменений.
- Работай только в этом проекте. Исходный OnixFrame starter не меняй.
- Сохраняй HTML/CSS/JS, используй Vite для dev и production-сборки; не добавляй
  лишние зависимости.
- Не минифицируй исходники. Каждый CSS-селектор и каждое CSS-свойство должны
  быть на отдельных строках.
- Используй Prettier из `package.json` и настройки `.prettierrc.json`; исходный
  CSS оставляй многострочным.
- Header должен оставаться sticky сверху на всём протяжении прокрутки; проверь
  desktop и mobile, фон, z-index и якорные отступы.
- Оригиналы храни в `assets/images/source/`, запускай `npm run images:process`.
  Подключай AVIF/WebP с fallback через `picture`, а размеры — через
  `srcset`/`sizes`, чтобы браузер выбирал вариант для обычной или
  Retina-плотности. Для отдельного мобильного кадра добавляй `<source media>`.
- Предпочитай фото, предоставленные заказчиком. Не называй стоковые или
  сгенерированные визуализации реальными работами; пока нет своих фото — оставь
  отмеченные плейсхолдеры.
- Используй alt, размеры изображения и lazy loading ниже первого экрана; главное
  hero-изображение загружай приоритетно.
- Подготовь базовое SEO: уникальные title/description, canonical после
  подтверждения домена, Open Graph, robots.txt, sitemap.xml. Структурированные
  данные добавляй только после получения проверенных данных бизнеса.
- Не выдумывай цены, адрес, телефон, сроки, гарантии, отзывы и рейтинг.
- Не размещай секреты в браузерном коде. Форма остаётся честно в демо-режиме до
  настройки Turnstile и Telegram.
- Не запускай тесты, если пользователь не просил их запускать.
