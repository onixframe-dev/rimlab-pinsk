# OnixFrame Starter Landing

Стартовый шаблон адаптивного сайта компании или услуги на чистых HTML, CSS и JavaScript.

## Что внутри

- Семантическая адаптивная страница с готовыми секциями: первый экран, преимущества, услуги, этапы, FAQ и заявка.
- CSS-токены и отдельные файлы для базы, компонентов и секций.
- Доступное мобильное меню, состояния фокуса и поддержка `prefers-reduced-motion`.
- SEO-заготовки: title, description, Open Graph, robots.txt и sitemap.xml.
- Форма с honeypot и обязательной серверной проверкой Cloudflare Turnstile.
- Vercel Function для отправки заявок в Telegram.
- Инструкции для Codex и Cline.

Шаблон специально не содержит фреймворков и npm-зависимостей. Подключайте библиотеку только при конкретной необходимости проекта.

## Быстрый старт

1. Создайте новый репозиторий из этого шаблона или склонируйте его.
2. Замените демонстрационные тексты, название проекта, контакты и юридическую информацию.
3. Разместите сайт на Vercel. Статические файлы обслуживаются как сайт, а `api/lead.js` работает как серверная функция.
4. Создайте сайт и секретный ключ в Cloudflare Turnstile. В `index.html` замените `REPLACE_WITH_TURNSTILE_SITE_KEY` на публичный Site Key.
5. В Vercel добавьте переменные окружения из `.env.example`. Секрет Telegram Bot Token добавляйте только в переменные окружения Vercel.
6. После добавления переменных пересоберите deployment.

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Секретный токен Telegram-бота |
| `TELEGRAM_CHAT_ID` | ID чата или канала, куда бот отправляет заявки |
| `TURNSTILE_SECRET_KEY` | Секретный ключ проверки Turnstile |
| `SITE_ORIGIN` | Разрешённый origin сайта, например `https://example.com` |

Все четыре значения необходимы для работы формы. Публичный Turnstile Site Key размещается в HTML и не является секретом. Не помещайте секретные ключи в клиентский JavaScript, HTML или Git.

## Локальный просмотр

Статическую часть можно открыть через любой локальный HTTP-сервер. Для проверки Vercel Function установите Vercel CLI и запустите `vercel dev`, затем задайте переменные окружения в локальном окружении.

Без переменных окружения API намеренно не принимает заявки. Это помогает не показывать посетителю ложное сообщение об успешной отправке.

## Перед запуском проекта

- Замените демонстрационные тексты, метаданные, домен в `robots.txt` и `sitemap.xml`.
- Создайте и опубликуйте настоящую политику конфиденциальности; текущая `privacy.html` — только каркас.
- Проверьте, что Telegram-бот добавлен в нужный чат и имеет право отправлять сообщения.
- Проверьте форму на production-домене с настоящими Turnstile-ключами.
- Для проектов с повышенным потоком заявок добавьте серверное ограничение частоты запросов, например через Upstash Redis.
- При подключении аналитики, пикселей или внешних шрифтов обновите политику конфиденциальности и настройки согласия.

## Редактирование дизайн-системы

Основные цвета, ширина контента, радиусы, типографика и интервалы заданы CSS-переменными в `styles/tokens.css`. Начинайте настройку нового проекта с этих токенов, затем меняйте секции и компоненты.
