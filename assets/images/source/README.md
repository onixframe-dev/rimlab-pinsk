# Исходные изображения

Кладите сюда утверждённые оригиналы фотографий и графики. Скрипт
`npm run images:process` создаёт оптимизированные варианты в
`public/images/optimized/`.

- Используйте понятные латинские имена: `wheel-service.jpg`, `wheel-before.jpg`.
- Для отдельной мобильной композиции добавьте самостоятельный файл с суффиксом
  `--mobile`, например `wheel-service--mobile.jpg`.
- Не помещайте сюда изображения, права на которые не подтверждены.
- Не редактируйте сгенерированные файлы вручную: измените оригинал и запустите
  обработку снова.
