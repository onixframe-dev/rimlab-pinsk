# Инструкции для AI-агентов

## Перед началом

- Прочитай этот файл и `README.md`.
- Уточни задачу по текущему коду и меняй только файлы, относящиеся к ней.
- Сохраняй простой стек шаблона: HTML, CSS и JavaScript без зависимостей, если проект явно не требует другого.

## Структура и стиль

- Сохраняй разделение токенов, базовых правил, компонентов и секций в `styles/`.
- Используй существующие CSS-переменные из `styles/tokens.css`; не дублируй значения цветов и размеров без причины.
- Пиши семантический HTML, доступные подписи, видимый focus и корректные состояния для клавиатуры.
- Проверяй узкие экраны, длинные тексты и системную настройку уменьшения анимации.
- Не добавляй изображения, библиотеки, сборщик или внешние скрипты без обоснованной задачи.

## Формы и безопасность

- Не помещай Telegram Bot Token, Turnstile Secret Key или другие секреты в браузерный код.
- Сохраняй серверную проверку Turnstile, проверку входных данных и honeypot.
- Не сообщай об успешной отправке, пока сервер не подтвердил её.
- Не выводи персональные данные посетителей и секреты в логи.

## Правила изменений

- Не перезаписывай пользовательские изменения, не относящиеся к задаче.
- Сохраняй SEO-метаданные, доступность и адаптивность при изменениях разметки.
- Не запускай тесты, если пользователь не просил тестирование или проверку.
- После изменений кратко перечисли файлы и укажи, что осталось настроить в окружении.
